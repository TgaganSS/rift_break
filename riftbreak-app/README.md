# Riftbreak: Android app project

## Build with GitHub (no Android Studio needed)
1. Upload everything in this folder to a new GitHub repo (keep the .github folder).
2. Open the repo's Actions tab. The "Build Android APK" workflow runs on its own.
3. When it shows a green tick, open the run and download "riftbreak-apk" under Artifacts.
4. Unzip it to get app-debug.apk and install it on your phone.

To update the game later, replace www/index.html in the repo and commit. A new APK builds automatically.
